# ระบบเช็คชื่อและบันทึกคะแนนนักเรียน

เว็บสำหรับเพิ่มรายชื่อนักเรียน สร้างคาบเรียน (วันที่ + ชื่อคาบ) เช็คชื่อเข้า-ออก และบันทึกคะแนน

- **เช็คเข้า + เช็คออก ครบ = ได้ 5 คะแนนอัตโนมัติ** · เช็คเข้าอย่างเดียว = 0 คะแนน
- แต่ละคาบเริ่มต้นว่าง เพิ่มนักเรียนเข้าคาบจากช่องค้นหาแบบดรอปดาวน์ ถ้าไม่มีในระบบเพิ่มชื่อที่พิมพ์เป็นนักเรียนใหม่ได้ทันที
- **เช็คออกแล้วคะแนนในคาบต่ำกว่า 10 = ติดแท็ก "ไม่ผ่าน"** (แก้เกณฑ์ได้ที่ `PASS_SCORE` ใน [lib/scoring.js](lib/scoring.js))
- **คลาสหลัก 5 บท** (บทนำ, บท 1 อ่านใบชา, บท 2 ไพ่พยากรณ์, บท 3 ลูกแก้วนิมิต, บท 4 คาถาทำสำเนา — แก้ได้ที่ [lib/lessons.js](lib/lessons.js))
  ถ้าเรียนบทเดิมซ้ำ คะแนนรวมจะนับเฉพาะครั้งที่ได้คะแนนสูงสุดของบทนั้น
  **บท 4 ต้องผ่านอย่างน้อย 2 บท (ไม่ซ้ำบท) จากบท 1–3** — คนที่ยังไม่ผ่านจะมีแท็ก ⚠ ต่อท้ายชื่อตอนเพิ่มเข้าคาบ (แก้เงื่อนไขได้ที่ `PREREQUISITES` ใน [lib/lessons.js](lib/lessons.js))
- **ในหน้าเช็คชื่อ: กด "± คะแนน" เพื่อเพิ่ม/ลดคะแนนในคาบ** พร้อมหมายเหตุ (เลือกจากรายการสำเร็จรูปหรือพิมพ์เอง — แก้รายการได้ที่ [lib/reasons.js](lib/reasons.js))
- แสดงคะแนนรวมของแต่ละคาบ และหน้าสรุปคะแนนทุกคาบ (ดาวน์โหลดเป็น CSV เปิดใน Excel ได้)
- ปุ่มเช็คเข้า/ออกทั้งห้องในคลิกเดียว
- **หน้านักเรียน**: รายชื่อแบบแบ่งหน้า ค้นหาชื่อ/รหัสได้ พร้อมคะแนนรวม และ**เพิ่ม/ลดคะแนนนอกคลาส**พร้อมหมายเหตุ (นับรวมในคะแนนรวม)
- **หน้ารายคน**: คะแนนรวมทุกคลาส ความคืบหน้าคลาสหลัก และ**ประวัติคะแนนทุกครั้ง** ว่าคาบไหน เปลี่ยนเท่าไร เพราะอะไร โดยใคร
- **ระบบล็อกอิน**: ทุกคนต้องเข้าสู่ระบบ ชื่อผู้ใช้จะถูกบันทึกในประวัติคะแนน
  ผู้ดูแลเพิ่มบัญชีครูได้ที่เมนู "ผู้ใช้"

เทคโนโลยี: Next.js + Postgres (Neon) — ใช้ฟรีบน Vercel

> เปลี่ยนจำนวนคะแนนเข้าเรียนได้ที่ `ATTENDANCE_POINTS` ใน [lib/scoring.js](lib/scoring.js)

## วิธี Deploy ขึ้น Vercel (ฟรี)

1. **อัปโค้ดขึ้น GitHub**
   ```bash
   git init
   git add .
   git commit -m "first commit"
   ```
   สร้าง repository ใหม่บน github.com แล้ว push ขึ้นไป

2. **สร้างโปรเจกต์บน Vercel**
   ไปที่ https://vercel.com → *Add New… → Project* → เลือก repo นี้ → กด *Deploy*
   (ครั้งแรกเว็บจะขึ้นข้อความว่ายังไม่ได้ตั้งค่า DATABASE_URL — เป็นเรื่องปกติ)

3. **เพิ่มฐานข้อมูลฟรี**
   ในโปรเจกต์บน Vercel → แท็บ *Storage* → *Create Database* → เลือก **Neon (Postgres)** → แผน Free
   → กด *Connect* กับโปรเจกต์นี้ ระบบจะใส่ `DATABASE_URL` ให้อัตโนมัติ

4. **Redeploy**
   แท็บ *Deployments* → เมนู ⋯ ของอันล่าสุด → *Redeploy*
   ตารางในฐานข้อมูลจะถูกสร้างเองตอนเปิดใช้งานครั้งแรก ไม่ต้องรัน SQL เอง

5. **สร้างบัญชีผู้ดูแล**
   เปิดเว็บครั้งแรกจะเจอหน้าให้สร้างบัญชี**ผู้ดูแล**คนแรก (ทำได้ครั้งเดียว — ควรรีบทำทันทีหลัง deploy)
   จากนั้นเพิ่มบัญชีครูคนอื่นได้ที่เมนู "ผู้ใช้"

6. **(แนะนำ) ตั้ง `AUTH_SECRET`**
   *Settings → Environment Variables* → เพิ่ม `AUTH_SECRET` = ข้อความสุ่มยาวๆ (เช่น 40 ตัวอักษร) แล้ว Redeploy
   ใช้เซ็นคุกกี้ล็อกอิน ถ้าไม่ตั้งระบบจะใช้ `DATABASE_URL` แทน

## รันบนเครื่องตัวเอง

```bash
npm install
npm run dev
```
เปิด http://localhost:3000

ถ้าไม่ได้ตั้ง `DATABASE_URL` ระบบจะใช้ฐานข้อมูลจำลองบนเครื่อง (PGlite) เก็บไว้ในโฟลเดอร์ `.data`
อยากล้างข้อมูลทั้งหมดให้หยุดเซิร์ฟเวอร์แล้วลบโฟลเดอร์ `.data` ทิ้ง
ถ้าอยากต่อกับฐานข้อมูล Neon จริง ให้คัดลอก `.env.example` เป็น `.env.local` แล้วใส่ `DATABASE_URL`

## โครงสร้างฐานข้อมูล

| ตาราง | เก็บอะไร |
|---|---|
| `students` | รหัส, ชื่อนักเรียน |
| `sessions` | ชื่อคาบ, วันที่ |
| `records` | การเช็คชื่อของนักเรียนแต่ละคนในแต่ละคาบ: เวลาเข้า, เวลาออก, คะแนนเพิ่ม, หมายเหตุ |
| `users` | บัญชีผู้ใช้ (รหัสผ่านเก็บแบบ hash) |
| `score_logs` | ประวัติคะแนนในคาบ: นักเรียน, คาบ, +/- เท่าไร, เหตุผล, ใครทำ, เมื่อไร |
| `student_summary` (view) | คะแนนรวมของนักเรียนแต่ละคน = คะแนนจากคลาส (ใช้กฎคะแนนสูงสุดของบท) + คะแนนนอกคลาส |

คะแนนในคาบ = เข้า-ออกครบ 5 + คะแนนที่เพิ่ม/ลดในคาบ · คะแนนรวมของนักเรียน = คะแนนในคาบทั่วไปทุกคาบ + คะแนนสูงสุดของแต่ละบทในคลาสหลัก + คะแนนนอกคลาส
ประวัติคะแนนลบไม่ได้ ถ้ากดผิดให้เพิ่ม/ลดกลับพร้อมใส่เหตุผล
